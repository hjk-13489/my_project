# Product Brief：校园二手书/闲置物品交易系统

## 执行摘要

福州大学旗山校区的学生要买卖二手书和闲置物品，现在的两条路都不好走：QQ 群里信息零散、良莠不齐、数量少，翻找费力；闲鱼等第三方平台功能虽全，却不是为校园内交易设计的，还带着物流、陌生交易这些校园场景里本不必要的负担。

本项目做一个**面向旗山校区学生的网页端二手交易平台**，用「同校身份」解决信任、用「当面交付」省掉物流，让学生能顺畅地完成「发布 → 浏览 → 联系 → 下单 → 交付 → 评价」的完整闭环。

它定位为一个**课堂作业**：尺度是「不过度复杂、也不过于简陋」，最终交付一个可演示的系统加一份足够完整的文档。

## 问题

- **现状 A — QQ 群**：买卖双方靠群聊建立连接，信息没有结构（价格、成色、图片、状态都不规范），量少且杂，想找一件合意的东西要翻很久。
- **现状 B — 闲鱼等第三方平台**：功能齐全但不面向校园内交易——物流、陌生交易、平台信任机制都是「同校当面」场景里本不需要的成本。
- **后果**：想卖的人卖不掉、卖得慢；想买的人找不到、只能买更贵的全新品；旧书和闲置物品就这么被浪费。

## 方案

一个网页端的校园二手交易平台，核心闭环：

**发布闲置 → 浏览/搜索 → 联系卖家 → 下单（模拟支付）→ 当面交付 → 确认收货 → 互评**

- 注册时做**学号/校园身份验证**，保证「同校」可信。
- **线上支付为模拟支付**，跑通订单状态流转即可，不接真实第三方支付。
- 交付以**同校当面交付**为主，因此不做物流模块。
- 另有**管理员后台**，负责审核/下架违规发布、处理交易纠纷、用户管理、数据统计看板。

## 为什么不同

- **「同校」是真实差异点**：身份可验证（学号）、可当面交付、纠纷可追溯，信任成本远低于闲鱼。
- **轻而专**：不做物流、不做真实支付，聚焦校园场景，砍掉闲鱼里对校园用户多余的部分。
- 诚实地说：这不是一个技术护城河，而是一个**场景 + 执行**的选择——把「同校」这张牌真正做出来（身份验证 + 当面交付），就是它区别于闲鱼的地方。

## 谁在用

- **主要用户**：福州大学旗山校区学生——买家和卖家是同一群人。
- **卖家**：想把旧书、闲置物品变现或腾地方的学生。
- **买家**：想低价买到教材、日用品的学生。
- **平台管理员**：审核/下架违规发布、处理交易纠纷、用户管理、查看数据统计看板，维护平台秩序。

## 成功标准

- **课程层面**：演示跑得顺——主流程（注册→发布→购买→交付→评价）无卡壳；文档足够全——能独立说明设计、功能与使用方式。
- **产品层面**：一个用户在不看帮助的情况下，几分钟内走完「注册 → 发布一件闲置」和「浏览 → 下单 → 模拟支付 → 确认收货 → 评价」的完整闭环；核心功能点（发布、搜索、联系、订单、评价）全部可用。

## 范围

**第一版包含**：
- 注册登录 + 学号/校园身份验证
- 发布闲置（标题、描述、价格、图片、成色、分类）
- 浏览 + 搜索/筛选
- 联系卖家：下单后展示卖家的 QQ/微信号及身份认证状态
- 下单 + 模拟支付 + 订单状态流转
- 评价（买卖双方互评）
- 管理员后台（审核/下架违规发布、处理交易纠纷、用户管理、数据统计看板）

**第一版明确不做**：
- 真实第三方支付
- 物流/快递配送（同校当面交付）
- 站内即时聊天

## 愿景

如果它做好，可以从旗山校区扩展到福大其他校区、乃至更多高校；从一份课堂作业，演变成真正有人用的校园闲置流通工具，并在开学季、毕业季形成专场效应。
